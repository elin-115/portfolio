## 접근

### 전처리에서 가장 중요했던 판단 — 「제품수」의 정체

원본은 **제품 1개 = 1행**이다. 그런데 변수 정의서의 `제품수`(1~11,252)가 무엇을 센 값인지 적혀 있지 않았다.

성분 조합으로 묶어 세어 보니 **(성분코드A, 성분코드B) groupby 크기의 최댓값이 정확히 11,252**로 일치했다.
즉 `제품수`는 **성분(조합)별 행 수**다. 이걸 모르고 행 단위로 분석하면 같은 성분 조합이 수천 번 중복 계산된다.

```python
df['제품수'] = df.groupby(['성분코드A','성분코드B'])['제품코드'].transform('size')
ingredient = df.drop_duplicates(['성분코드A','성분코드B'])
```

성분 단위로 바꾼 뒤 행 수 — 병용 23,639 / 임부 4,011 / 연령 607 / 노인 150 / 노인해열 95.

## 결과

| | 분석 | 결과 |
|---|---|---|
| Q1 | 금기 사유 최빈 키워드 | 행 기준으로는 촉진·신부전·유산·산성 — 전부 메트포르민-조영제 문장이 반복된 탓. **중복 제거하면 증가·농도·감소로 바뀜** |
| Q2 | 고시일 기준 등급 차이 | Mann-Whitney p=4.8e-38로 "유의"하지만 **중앙값은 양쪽 다 9.73으로 같다.** 2016-12-30 일괄 고시에 몰려 생긴 착시 |
| Q3 | 제형별 1등급 비율 | 내복 19.8% > 주사 10.1% > 외용 5.9% (χ²=81.3, p=2.2e-18) |
| Q4 | Word2Vec 유사어 | '태아' ≈ 태자·모체. 문장 3,840개 규모에서는 **CBOW가 Skip-Gram보다 뚜렷하게 나았다** |
| Q5 | 최다 병용금기 조합 | metformin + iohexol, 86,404건 |
| Q6 | 등급 분류 (RandomForest) | **0.958** — 정형 변수만 쓰면 0.567. 즉 **판별력은 텍스트에서 나온다** |
| Q7 | 등급 분류 (SimpleRNN) | 0.884, 1등급 재현율 0.891 |
| Q8 | 토픽 모델링 (LDA, k=5) | 약효감소 / 근육·혈관독성 / 투여금기 / 증후군 / 심혈관 (perplexity 106.9) |

### Q2에서 배운 것

p값이 작다고 차이가 의미 있는 건 아니다.
표본이 2만 건을 넘으면 중앙값이 **완전히 같아도** p=4.8e-38이 나온다.
평균(9.01 vs 7.72)이 갈린 것도 2016-12-30 일괄 고시 건이 한쪽에 몰렸기 때문이고, 약의 성질과는 무관했다.
