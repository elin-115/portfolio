# 네이버 블로그 자동화

관심분야만 넣으면 **글감 발굴 → 초안 작성 → 이미지 매칭 → 네이버 발행**까지 이어지는 로컬 웹앱.
전부 내 컴퓨터에서만 돌아간다. 외부로 나가는 건 네이버·검색·이미지 요청뿐이다.

```
관심분야 입력
   ↓  네이버 뉴스·인기 블로그 수집 (Playwright)
   ↓  AI가 지금 쓸 만한 글감 선별
   ↓  AI가 자료를 근거로 글을 새로 작성
   ↓  이미지 후보 수집 → AI가 사진을 직접 보고 판정
   ↓  ★ 사람이 검토하고 [발행] 클릭 ★
   ↓  스마트에디터 자동 작성 + 서식 + 발행
```

---

## 설치

```bash
npm install
npm run install-browser
npm run doctor
```

`npm run doctor`가 모든 항목을 점검하고, 빠진 게 있으면 해결법을 알려준다.

```bash
npm start
```

→ http://localhost:3000

---

## 처음 한 번만

1. **네이버 로그인** — 상단 `네이버 로그인 필요` 칩을 클릭하면 브라우저 창이 뜬다.
   거기서 **직접** 아이디·비밀번호를 입력한다.
   이 앱은 비밀번호를 절대 다루지 않는다. 로그인이 끝나면 세션 쿠키만 `data/session/`에 저장되고,
   다음부터는 이 세션을 재사용한다.

2. **AI 연결 확인** — `AI 연결 안 됨` 칩을 클릭한다.
   실패하면 터미널에서 `claude`를 실행한 뒤 `/login` 하면 된다.
   API 키가 아니라 **구독 계정**을 그대로 쓴다 (`claude -p` 서브프로세스).

3. **설정** — 내 블로그 아이디(`blog.naver.com/여기`)를 넣는다. 없으면 발행이 안 된다.

## 이미지 소스

| 소스 | 저작권 | 설정 |
|---|---|---|
| Unsplash · Pexels | 상업적 사용 가능 | `.env.example` → `.env` 복사 후 무료 키 입력 |
| 로컬 폴더 | 내가 보유 | `data/local-images/` 에 사진을 넣어둔다 |
| 네이버 이미지 검색 | **미확인** | 켤 수 있지만, 사용 전 출처를 직접 확인해야 한다 |

스톡 키가 없으면 스톡 소스는 자동으로 건너뛴다. 저작권 안전을 원하면 무료 키 발급을 권한다.
([Unsplash](https://unsplash.com/developers) · [Pexels](https://www.pexels.com/api/))

수집한 이미지는 **AI가 파일을 직접 열어서** 해당 문단에 어울리는지 판정한다.
점수(0~100), 통과/탈락, 사유가 검토 화면에 그대로 표시된다. 60점 미만은 자동 탈락이고,
전부 탈락하면 그 자리는 비워둔 채 사유를 남긴다.

## 계정 보호

네이버는 자동화를 좋아하지 않는다. 다음을 지키도록 만들어져 있다.

- **하루 발행 한도** 기본 3건 (설정에서 변경). 초과하면 발행이 막힌다.
- 사람처럼 한 글자씩 입력하고, 요청 사이에 불규칙한 간격을 둔다.
- 로그인 세션을 재사용해 반복 로그인을 피한다.
- **캡차가 뜨면 자동으로 뚫지 않는다.** 창을 띄운 채 멈추고 사람에게 넘긴다.
- 발행은 기본적으로 **창을 띄운 상태**로 진행한다. 문제가 생기면 바로 개입할 수 있다.

그래도 위험이 0은 아니다. 중요한 계정이라면 테스트 계정으로 먼저 돌려보길 권한다.

## 셀렉터가 깨졌을 때

네이버는 클래스명에 해시를 붙여 수시로 바꾼다. 수집이나 발행이 갑자기 안 되면 대개 이것이다.

1. `data/debug/` 에 실패 시점 스크린샷과 HTML이 남아 있다. 먼저 그것을 본다.
2. 에디터 문제라면 점검 모드를 돌린다.

```bash
node src/publish.js --inspect 내블로그아이디
```

어떤 셀렉터 후보가 잡히고 안 잡히는지 ✅/❌로 출력한다.

3. `config/selectors.js` 를 고친다. **셀렉터는 전부 이 파일 한 곳에 있다.**
   각 항목은 후보 배열이라, 새 셀렉터를 배열 맨 앞에 추가하면 된다.

## 구조

```
config/selectors.js   ← 네이버 DOM 셀렉터 (깨지면 여기만 고친다)
src/
  ai.js         claude -p 래퍼 (구독 인증)
  browser.js    Playwright 컨텍스트 · 세션 유지 · 디버그 덤프
  auth.js       네이버 로그인 (사람이 직접 입력)
  collect.js    뉴스 · 블로그 수집
  ideas.js      글감 선별
  writer.js     본문 생성 (블록 배열)
  images.js     이미지 수집 + AI 판정
  publish.js    스마트에디터 작성 · 발행 (--inspect 모드 포함)
  pipeline.js   4단계 오케스트레이션
  server.js     Express API + SSE
  doctor.js     환경 점검
public/         대시보드 (빌드 없는 바닐라 HTML/CSS/JS)
data/           세션 · 초안 · 이미지 · 디버그 (전부 git에서 제외)
```

## 데이터는 어디에 있나

전부 `data/` 아래, 이 컴퓨터에만 있다.

- `data/session/` — 네이버 로그인 세션 (크롬 프로필)
- `data/posts/` — 초안 JSON
- `data/images/` — 내려받은 이미지와 AI 판정 결과
- `data/debug/` — 실패 시점 스크린샷
- `data/settings.json` — 설정

세션을 지우려면 설정 모달의 `네이버 세션 삭제`를 누르거나 `data/session/`을 지우면 된다.
