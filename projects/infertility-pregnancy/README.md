# 난임 환자 임신 성공 확률 예측

난임 시술 기록으로 **임신 성공 여부**를 예측한 해커톤. 평가 지표는 ROC-AUC.

OZ코딩스쿨 AI 헬스케어 7기 해커톤 · **2위** · 2026.08.28 ~ 2026.09.04

---

## 데이터

시술 1건 = 1행, 256,351건. 시술 유형은 IVF(체외수정) 250,060건 · DI(기증정자 인공수정) 6,291건.
환자 특성(연령대·불임 원인), 시술 이력(시술·임신·출산 횟수), 배아·난자 수치, 경과일 등으로 구성된다.

> 해커톤에서 제공받은 데이터라 저장소에 포함하지 않았다.

## 접근

### 1. 빈칸의 뜻을 먼저 갈랐다

이 데이터에서 가장 중요했던 판단이다. "해당 없음"과 "미기록"이 같은 빈칸으로 들어온다.

IVF와 DI로 나눠 결측률을 다시 재니 구분이 됐다.

| 그룹 | 패턴 | 처리 |
|---|---|---|
| A — 배아·난자 지표 20개 | DI에서 100% 결측, IVF에서는 거의 없음 | 진짜 "해당 없음" → 0 (평균 대체 금지) |
| B — 경과일 계열 | IVF에서도 부분 결측 | 0일은 "당일"이라는 실제 값 → NaN 유지 + 결측 플래그 |
| "알 수 없음" 문자열 | 배란 유도 유형의 24% | 배란 자극 여부로 갈라 "안 함"과 "미기록"을 분리 |

DI는 배아를 만드는 과정이 없으니 "이식된 배아 수"가 비어 있는 것은 결측이 아니다.
이걸 평균으로 채우면 존재할 수 없는 값을 만들어 넣게 된다.

### 2. 상한에서 잘린 값을 찾았다

서로 다른 8개 컬럼의 최댓값이 **정확히 51.0**으로 같았다. 개인정보 보호용 상한 캡핑으로 보고 플래그로 표시했다.
(뒤에서 이 플래그들은 중요도 0으로 나와 제거했다 — 원본 수치가 이미 같은 정보를 담고 있었다.)

### 3. 파생변수

- 순서형 인코딩 — 연령대, `N회` 계열 10개
- 비율 — 수정률 · 배아생성률 · 배아저장률 · 이식률 · 미세주입활용률 (분모 0은 NaN)
- 조합 — 과거 실패 횟수, 불임 원인 개수, 미사용 배아 수, 연령×시술횟수

## 결과

XGBoost · Stratified 5-fold · 범주형은 `enable_categorical`로 직접 처리.

| 단계 | 피처 수 | 5-fold AUC |
|---|---|---|
| 베이스라인 | 124 | 0.73992 |
| 중요도 0 피처 23개 제거 | 101 | 0.73997 |
| Optuna 튜닝 (25 trial) | 101 | **0.74029** |

fold별 AUC는 0.738~0.743으로 고르게 나왔다(표준편차 0.002).

**가장 중요한 변수는 이식된 배아 수(중요도 17.5%)**, 그다음이 시술 유형(10.6%)이었다.
연령대별 성공률은 만 18–34세 32.3% → 만 43–44세 11.8%로 단조 감소했다.

### 여기서 배운 것

튜닝으로 얻은 것은 +0.0004였다. 피처 23개를 빼도 성능이 그대로였다.
**이 문제에서 성능을 가른 것은 모델 설정이 아니라 결측의 의미를 어떻게 해석했느냐였다.**
