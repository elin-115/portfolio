## 1. TCCC 외상 후 응급처치 데이터 분석

**전술적 전투 부상자 처치(TCCC)** 시나리오. 헬멧 캠으로 찍은 1인칭 영상에서
현장 응급처치 술기를 자동으로 인식·보조하는 AI를 상정하고, 그 전 단계인 데이터 분석을 맡았다.

국방·응급의료 AI 연구팀이 발주한 상황을 가정한 미션 시나리오형 과제다.
[`triage-soms`](../triage-soms)의 MARCH 규칙 엔진과 주제가 이어진다.

노트북: [`notebooks/tccc_외상_응급처치_분석.ipynb`](notebooks/tccc_외상_응급처치_분석.ipynb) — 코드 24셀 중 20셀 실행
